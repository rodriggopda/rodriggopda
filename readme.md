Acredito que onde não há persistência o sucesso jamais existirá. Também costumo acreditar que para tudo há um momento certo de acontecer, por mais árduo que seja a caminhada rumo a um objetivo.

Falando de minhas stacks e habilidades, hoje meu trabalho é focado 100% em serviçoss para a internet. Usando tecnologias como o bom e velho typescript, grande aliado da linguagem favorita dos webdev, o javascript.
Para construir protótipos hoje utilizo o figma, uma ferramenta que ganhou meu total respeito, mas também ja trabalhei com adobe XD e até me aventurei recentemente com o mais novo penpot, uma ferramenta que também considero excelente para trabalhos de prototipação e desenvolvimento de experiência do usuário.
Na construção de telas navegáveis e componentes reutilizáveis, hoje sou mais inclinado a utilizar o reactjs, por ser uma biblioteca de front-end que considero extremamente fácil de usar, apesar de já ter enfrentado alguns problemas um tanto quanto engraçados. Mas, ainda tenho uma queda pelo Vuejs. Esse que foi um dos primeiros frameworks front-end que usei, lá em meados de 2017/18.
Do lado do backend, uso nodejs, uma engine que considero poderosíssima, apesar de já ter flertado com outras linguagens como go e C#, mas até hoje não encontrei nada que elas fazem e que o javascript não possa fazer também. Apesar de serem excelentes tecnologias.
Para banco de dados, costumo não curtir muito o uso de noSQL e uso bastante o mysql nas aplicações, sempre atendeu muito bem.
Um detalhe sobre minha jornada em programação, php foi a primeira linguagem que usei para fazer alguma coisa, mas ao longo dos meus estudos comecei a dar mais espaço para o javascript e hoje é minha 'bala de prata' para qualquer coisa.
